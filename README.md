# Death Relapse
Game hành động 2D top-down (Unity, C#) — đồ án chuyên ngành CMP436, HUTECH, HK1 2026–2027.

## Mục tiêu
Nghiên cứu: báo đòn đa kênh (màu + hình + âm) có giúp người chơi nhận đúng loại đòn
và quy lần thua cho bản thân nhiều hơn không? Game là công cụ để đo hai chỉ số này.

## Kế thừa từ ĐACS
Không dùng lại mã nguồn hay asset. ĐACS là game thẻ bài theo lượt; đồ án này là
game hành động thời gian thực. Chỉ kế thừa kỹ năng Unity/C# và quy trình Git.

## Kế hoạch
W4: lõi chiến đấu + Né hoàn hảo · W5: Parry, boss, hai chế độ báo đòn · W6: Khát máu LV1–3

## Công nghệ
Unity, C#, GitHub Actions (GameCI), itch.io, Google Sheets
